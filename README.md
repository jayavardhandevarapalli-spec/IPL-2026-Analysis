# IPL 2026 Batsmen Performance Analysis

## Overview
Analysis of IPL 2026 batting performance using Python and Power BI.

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Power BI
- Kaggle Dataset

## Analysis Done
- Top 10 Run Scorers
- Strike Rate Analysis
- Boundary Hitters (4s and 6s)
- Team Total Runs

## Key Findings
- Vaibhav Suryavanshi topped run charts
- RR scored highest team runs
